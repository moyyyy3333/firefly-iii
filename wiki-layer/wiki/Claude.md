# Claude

> Claude is Anthropic's family of large language models and the assistant
> products built on top of them.

## What it is

Claude is a general-purpose AI assistant developed by **Anthropic**. It is
available through several surfaces:

- **claude.ai** — the web/desktop/mobile chat app
- **The Claude API** (formerly the Anthropic API) — programmatic access for
  developers (see [[Claude_API]])
- **[[Claude_Code]]** — an agentic coding tool that runs in the terminal,
  IDEs, and the cloud
- Cloud platforms (e.g. Amazon Bedrock, Google Vertex AI)

## Model family

The current generation is **Claude 4.x**, split into three tiers by the
capability/speed/cost trade-off: see [[Claude_Models]].

## Design priorities

Anthropic emphasizes **helpful, honest, and harmless** behavior, trained in
part via Constitutional AI. Claude is positioned for reliable reasoning, long
context, tool use, and agentic workflows.
