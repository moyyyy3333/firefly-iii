Bridge Commands — copy & paste these

⚡ First-time setup

1. Go into the bridge folder
cd hermes-vault/bridge
2. Install dependencies
npm install
3. Create your config file
cp config.example.json config.json
4. Open config.json and add your API keys

🗣 Chat with one AI

node index.js chat --ai claude "Your question here" node index.js chat --ai gpt "Your question here" node index.js chat --ai gemini "Your question here" node index.js chat --ai hermes "Private question"

Each one saves automatically to the right folder in your vault.

⚖️ Compare all AIs at once

node index.js compare "What should I focus on this week?"

Asks all enabled AIs the same question in parallel, then saves a comparison note in Synthesized/.

📥 Import an existing chat

node index.js import --ai gpt --title "My chat" chat.txt

Copy-paste any conversation from a browser into a .txt file, then import it into the vault.

📊 See today's activity

node index.js brief

Shows all the notes you've saved today across every AI.

🔍 Search your vault

node index.js search "machine learning" node index.js search "product idea"

Scans every note for the keyword and shows matching files.

🦙 Local Hermes setup (optional)

For completely private, offline AI:

# Install Ollama (Mac) brew install ollama # Start it ollama serve # Download the model ollama pull nous-hermes3
