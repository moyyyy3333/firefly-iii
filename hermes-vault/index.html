Bridge Commands — copy & paste

⚡ First-time setup

1. Go to bridge folder
cd hermes-vault/bridge
2. Install
npm install
3. Create config
cp config.example.json config.json

Then open config.json and paste in your API keys.

🗣 Chat with one AI

node index.js chat --ai claude "question"
node index.js chat --ai gpt "question"
node index.js chat --ai gemini "question"
node index.js chat --ai hermes "private Q"

Each saves automatically to the right vault folder.

⚖️ Compare all AIs at once

node index.js compare "Your question"

Asks every enabled AI the same question in parallel. Saves a comparison note in Synthesized/.

📥 Import an existing chat

node index.js import --ai gpt \
  --title "My chat" chat.txt

Paste any browser conversation into a .txt file and import it into the vault.

📊 See today's saves

node index.js brief

Lists every note saved today across all AIs.

🔍 Search all your notes

node index.js search "topic"

Scans every note for the keyword and shows file names + matching lines.
